# Gerenciador de Tarefas

API REST desenvolvida em Python com FastAPI e MySQL para gerenciamento de tarefas e autenticação de usuários.

## Funcionalidades

- Criar, consultar, atualizar e excluir tarefas
- Listar todas as tarefas
- Cadastro de usuários
- Login de usuários
- Hash de senhas

## Tecnologias

- Python
- FastAPI
- MySQL
- mysql-connector-python
- pwdlib
